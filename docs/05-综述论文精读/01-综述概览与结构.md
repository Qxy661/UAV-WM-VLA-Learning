## 综述的核心问题

这篇综述要回答的核心问题是：

> **世界模型如何与机器人学习耦合，推动机器人智能的发展？**

具体包括：
1. 世界模型在机器人学习中扮演什么角色？
2. 世界模型有哪些技术范式？
3. 世界模型如何用于策略学习、仿真评估、视频生成？
4. 有哪些数据集、基准和评估协议？

## 三项核心能力：综述自己的说法

综述在引言里给出的不是"三种角色"，而是世界模型应具备的**三项核心能力**：**foresight（前视预测）**、**imagination-driven planning（想象驱动的规划）**、**data amplification（数据放大）**。

下面按综述正文的三大部分（§3 策略 / §4 模拟器 / §5 视频生成）再展开——**这个"角色"划分是本仓库按章节顺序重整的，不是综述原文的提法**，读原文时不要去找这三个词。

### 角色一：作为策略 (Policy)

世界模型直接充当或辅助机器人策略：

```
传统策略: 观测 → 动作
世界模型策略: 观测 → 未来预测 → 动作
```

**子类别**（对应综述 §3.2–§3.6，五类）：
- **IDM风格**：先预测未来视觉轨迹，再用逆动力学模型提取动作
- **单骨干**：用一个统一模型同时建模视频和动作
- **MoE/MoT**：视频和动作专家分离，通过注意力机制交互
- **统一VLA**：将世界建模作为训练目标内化到VLA中
- **隐空间**：在表示空间中做未来预测，不显式生成视频

### 角色二：作为模拟器 (Simulator)

世界模型作为学习环境用于策略改进：

```
学习世界模型 → 在世界模型中"想象"交互 → 改进策略 → 部署到真实环境
```

**两种用途**：
- **强化学习**：Dreamer系列，用世界模型生成训练数据
- **评估**：用世界模型评分候选行为、排序策略、支持MPC规划

### 角色三：作为视频生成器 (Video Generator)

世界模型生成机器人视频用于多种目的：

```
视频生成 → 数据增强 / 想象训练 / 演示生成
```

## 关键发现

### 1. 世界模型与策略的耦合越来越紧密

从早期的"世界模型辅助策略"到现在的"世界模型即策略"，边界在模糊。

### 2. 视频生成世界模型快速发展

从想象式生成到可控、结构化、基础规模的公式化。

### 3. 隐空间世界建模兴起

JEPA风格的方法在表示空间中做未来预测，避免了像素空间生成的高成本。

### 4. 基准和评估标准化

综述总结了代表性的数据集、基准和评估协议。

2. **分类思考**：IDM策略和单骨干策略的核心区别是什么？各有什么优劣？

3. **无人机适配**：综述的分类框架如何映射到无人机领域？有哪些无人机特有的类别？

4. **趋势判断**：你认为世界模型作为策略 vs 作为模拟器，哪个方向更有前景？

5. **进阶思考**：为什么隐空间世界建模（如JEPA）可能比像素空间生成更适合无人机？

<details><summary>参考答案</summary>

1. 两层要分开：综述自己给的是**三项核心能力**——foresight（前视预测）、imagination-driven planning（想象驱动的规划）、data amplification（数据放大）；本仓库的「策略 / 模拟器 / 视频生成器」是按综述 §3/§4/§5 的章节顺序重整出来的角色划分，便于对照，**但原文没有这三个词**。三大部分的实质内容是：**作为策略**——世界模型直接充当或辅助机器人策略，通过未来预测来输出动作；**作为模拟器**——世界模型作为学习环境，让策略在"想象"中进行强化学习或评估规划；**作为视频生成器**——世界模型生成机器人视频，用于数据增强、想象训练或演示生成。

2. IDM策略将视频预测和动作提取分为两步，先生成未来视觉轨迹再用逆动力学模型恢复动作，模块化且可解释但推理延迟高；单骨干策略用一个统一模型同时建模视频和动作，端到端训练简洁高效但模型规模大、可解释性差。

3. 综述框架可直接映射到无人机领域：IDM对应ANWM的FFP模块，统一VLA对应VLA-AN和CognitiveDrone，世界模型作为模拟器对应Dream to Fly，视频生成对应FlightDiffusion和MotionScape。无人机特有类别包括面向3D空间感知的IDM扩展和适配空中机动的隐空间世界建模。**注意这只是框架的搬运，综述本身没有引用任何无人机论文。**

4. 两种方向各有适用场景。作为策略更契合端到端部署趋势，适合需要实时响应的场景；作为模拟器则在安全关键场景中更有优势，允许在虚拟环境中充分验证策略。对于无人机，两者结合（在模拟器中训练再部署为策略）可能是最务实的路径。

5. 隐空间世界建模在表示空间中做未来预测，避免了像素级生成的巨大计算开销；无人机机载算力有限，隐空间方法推理速度快、内存占用低，更适合实时控制；同时它规避了视频生成中的累积误差问题，预测稳定性更好。
