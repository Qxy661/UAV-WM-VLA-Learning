# 导读与学习路线

> 预计阅读：10 分钟 | 前置知识：无

---

## 这个项目是什么

本项目是一个**无人机领域的 VLA/VLM/世界模型学习知识库**，目标是帮助你：

1. **理解三大核心概念**：世界模型（World Model）、视觉语言模型（VLM）、视觉语言动作模型（VLA）
2. **掌握领域全景**：知道这个领域在研究什么、怎么分类、关键论文有哪些
3. **深入无人机方向**：理解这些技术如何应用于无人机，与地面机器人有何不同
4. **获得动手能力**：知道如何复现关键项目，即使暂时不跑代码也能理解流程

---

## 你需要什么前置知识

| 知识领域 | 最低要求 | 理想水平 |
|----------|---------|---------|
| **深度学习** | 知道什么是神经网络、CNN、Transformer | 了解预训练、微调、注意力机制 |
| **计算机视觉** | 知道什么是图像分类、目标检测 | 了解语义分割、光流、视觉里程计 |
| **强化学习** | 知道什么是状态、动作、奖励 | 了解策略梯度、Actor-Critic |
| **自然语言处理** | 知道什么是Token、语言模型 | 了解BERT/GPT架构 |
| **无人机基础** | 知道什么是四旋翼、PID控制 | 了解MAVLink、ROS2、PX4/ArduPilot |

**不需要**：CUDA编程、机器人学深入知识、硬件经验

## 学习路线图

### 阶段一：建立认知框架（1周）

```
目标：理解三大概念是什么、有什么关系
路径：00-导读 → 01-基础概念(5篇)
输出：能用自己的话解释 VLM、VLA、世界模型
```

**推荐阅读顺序**：
1. 什么是世界模型 — 理解"预测未来"的核心思想
2. 什么是VLM — 理解"看图说话"的基础
3. 什么是VLA — 理解从"理解"到"行动"的演进
4. 三者关系与区别 — 串联三者的关系
5. 无人机vs地面机器人 — 理解无人机的特殊性

### 阶段二：选择方向深入（2-3周）

```
目标：深入理解一个方向的论文和方法
路径：02/03/04 专题（选一个或多个）
输出：能分析一篇论文的创新点和局限性
```

**方向选择建议**：

| 方向 | 适合人群 | 核心问题 |
|------|---------|---------|
| **世界模型** | 对预测/仿真/数据生成感兴趣 | 如何让无人机"想象"未来会发生什么 |
| **VLA** | 对端到端控制感兴趣 | 如何让无人机"看+说+飞"一体化 |
| **VLM** | 对感知/理解感兴趣 | 如何让无人机"理解"看到的内容 |

三个方向里 **VLA 专题（10 篇）**已经按"在什么轴上做消融"重新组织过：01 是架构演进路线图，02–04 是无人机专章（专用模型、语言条件控制、基础模型辅助规划），05 讲机载部署，06–10 五篇各管一根轴 —— [动作接口](03-VLA专题/06-动作头与动作分块.md)、[数据与预训练](03-VLA专题/07-数据、预训练与跨具身.md)、[后训练](03-VLA专题/08-强化学习后训练与自我改进.md)、[评测口径](03-VLA专题/09-评测基准与报告口径.md)、[世界模型的接法](03-VLA专题/10-世界模型增强VLA.md)。按轴读还是按时间读都可以，轴划分的理由见 [01-VLA架构演进 §7.3](03-VLA专题/01-VLA架构演进.md)。

**世界模型专题（9 篇）**：01–06 是主干（发展史、生成式、RSSM 类、3D 表示、无人机世界模型综述、关键数据集与基准），07–09 三篇各覆盖一根独立的轴 —— [评测与诊断](02-世界模型专题/07-世界模型评测与诊断.md)、[联合嵌入预测与潜空间世界模型](02-世界模型专题/08-联合嵌入预测与潜空间世界模型.md)、[长时程与交互式生成](02-世界模型专题/09-长时程世界模型与交互式生成.md)。

**VLM 专题（7 篇）**的缺口与另两卷不同：01–04 都是无人机/遥感侧的应用与部署，**通用 VLM 的方法主干整体缺席** —— 而 [VLM 专题自测](09-专题自测与考察/03-VLM专题自测.md) 的考题早就在考视觉编码器、连接器与幻觉评测。所以 05–07 三篇补的是这条主干，**建议在读 01/02 之前先读**：[通用VLM架构与视觉编码器](04-VLM专题/05-通用VLM架构与视觉编码器.md)（四个部件、CLIP→原生分辨率、连接器、token 预算）、[VLM指令微调与对齐](04-VLM专题/06-VLM指令微调与对齐.md)（指令数据构造、LoRA 的边界、冻结还是联合训练）、[通用VLM评测与幻觉](04-VLM专题/07-通用VLM评测与幻觉.md)（评测口径、POPE 与负样本划分）。三篇里 05 与 07 各配一个可跑的验证实验，06 因本仓算力条件所限不配 demo，理由写在篇首。

## 常见问题

**Q: 我需要跑代码吗？**
A: 不强制。本项目是认知优先的学习项目，重点在理解原理，**不跑代码完全不影响阅读**。但部分文档的 `## 动手验证` 一节配了可直接运行的迷你 demo（真 PyTorch，CPU 两三分钟），用真实跑出来的数字支撑正文的结论 —— 想动手时照着敲即可，也可改参数看结论怎么变。实践指南（Part 7）讲的是"怎么复现论文级项目"，比 demo 重得多。

**Q: 我应该按什么顺序读？**
A: 先读导读（本文档），再读基础概念（Part 1），然后选择感兴趣的方向深入。详见上方学习路线图。

**Q: 这个项目和原综述论文（arXiv:2605.00080）是什么关系？**
A: 本项目以该综述为骨架，但聚焦于无人机领域，补充了大量无人机专属论文和实践指南。综述面向通用机器人，本项目面向无人机。

**Q: 论文链接打不开怎么办？**
A: 大部分论文在 arXiv 上可以直接访问。如果打不开，可以尝试用论文标题在 Google Scholar 搜索。
