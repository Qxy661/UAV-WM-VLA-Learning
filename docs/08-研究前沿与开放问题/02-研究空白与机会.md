## 为什么关注研究空白

研究空白是论文创新的起点。这里只收**已被论文提及但尚未解决**的问题，不收泛泛的方向展望。

## 一、世界模型方向的空白

### 1.1 无人机专属世界模型匮乏

通用机器人世界模型（DreamerV3、DIAMOND、UniSim）发展迅速，专门面向无人机的却屈指可数——综述 arXiv:2605.00080 全文未出现 UAV / drone / aerial 任何一处，**该综述完全没有覆盖无人机专属世界模型**。缺的是能建模 3D 空间飞行动力学、能处理快速视角变化和变高度、并且能扩展到多机协同的模型。一个具体切入点是：把 DreamerV3 的 RSSM 适配到 3D 运动空间，加入高度维度和姿态状态。

> **勘误（2026-10）**：本节早先写作「该综述引用的 40+ 篇世界模型论文里，只有 2-3 篇聚焦无人机」。经全文检索，arXiv:2605.00080 中 UAV / drone / aerial 命中数为 **0**。原句把「覆盖很少」夸大成了「有 2-3 篇」，已改为「完全未覆盖」。

### 1.2 sim-to-real 差距未被量化

几乎所有论文都把 sim-to-real 差距列为核心挑战，但没有人系统量化过它：没有标准评估协议，AirSim / Gazebo / PyBullet 与真实环境的差距没有对比研究，世界模型能否缩小这个差距也缺乏实证。可做的题：做一个包含多种仿真器和真实飞行数据的对比基准，把差距量出来。

### 1.3 隐空间世界建模在无人机上的应用

JEPA 风格的隐空间世界建模在机器人操作中已经兴起（VIP，arXiv:2210.00030），无人机领域几乎空白。这里的疑问是：无人机视觉的高动态性能否用隐空间表示、隐空间预测能否避开像素生成的累积误差、推理频率能不能追上实时控制的需求。可做的题：在 gym-pybullet-drones 上对比两个空间的预测精度和推理速度。

> **勘误（2026-10）**：本节早先并列举了「VIP、3D-VPA」两项。**「3D-VPA」在 arXiv 与文献中均不存在**，已删除；保留的 VIP（arXiv:2210.00030）真实可查。另外原文的「推理速度够不够 50Hz」用的是本仓库早先自拟的未证实档位，已改为不指定数值的表述。

## 二、VLA 方向的空白

### 2.1 实时性瓶颈未解决

VLA-AN 报告的 8.3x 加速（**4100 ms → 494 ms**）是**网络前向**的数字，端到端整环仍未追上实时控制；CognitiveDrone 在机载平台上延迟更高。蒸馏或量化到哪一档还能保住精度、能不能反过来设计天生就跑得动的轻量 VLA，都还没有答案。可做的题：把 OpenVLA 蒸馏到 <1B，在 Jetson Orin 上把“延迟—精度”曲线量出来。

> **勘误（2026-10）**：本节早先写作「8.3x 加速（100ms → 12ms）」。8.3 这个倍数是真的，但两个端点数字是编的——arXiv:2512.15258 原文的基线对照是 4100 ms → 494 ms。已换成原文数字。

### 2.2 语言条件飞行控制的泛化性

UAV-Flow 证明了语言条件控制可行，但只在有限的指令类型上验证过。没验证的是复合指令（“先飞到红房子旁边，然后绕一圈，降落在屋顶”）、开放词汇（训练集外的物体和场景），以及中文指令与英文指令的效果差异。可做的题：在 UAV-Flow 基础上把指令复杂度和词汇开放度都往上推。

### 2.3 VLA 安全约束集成

VLA 端到端输出动作，中间没有显式的安全约束：输出层没有 CBF 或安全层，安全约束会不会拖低任务成功率也没有数据，紧急情况下的回退策略同样空缺。可做的题：在 VLA-AN 的动作输出端接一个 Control Barrier Function，把安全性—性能的权衡测出来。

## 三、VLM 方向的空白

### 3.1 无人机视角的 VLM 适配

GeoChat 是遥感 VLM 的代表，但它针对的是卫星和航拍正射影像，不是无人机 FPV 视角。FPV 的倾斜、快速变化和运动模糊，低空近距离场景，以及实时视频流而非单帧，都需要单独适配。可做的题：用无人机 FPV 数据微调 GeoChat，对比遥感视角与 FPV 视角的理解差异。

### 3.2 多模态融合不充分

大部分 VLM 只吃视觉加文本，无人机上的其他传感器都浪费了：IMU、GPS、气压计没有融合进来，深度信息（ToF/双目）没有整合，多机协同时的共享视觉信息也没被利用。可做的题：设计一个融合视觉与惯导的 VLM 架构，测多模态是否真的提升场景理解。

## 四、评估与基准的空白

### 4.1 缺乏统一评估框架

不同论文用不同的仿真环境、评估指标和数据集，横向对比基本做不了。缺的是类似自动驾驶 CARLA 那样的标准无人机 VLA 评估平台、标准化的 sim-to-real 评估协议，以及统一的计算成本口径（FLOPs、延迟、内存）。可做的题：设计一套包含标准场景、指标和提交协议的评估框架。

### 4.2 安全性评估缺失

论文主要报告成功率，很少评估失败模式的安全性：失败是软着陆还是坠毁、低电量/强风/传感器故障下会怎么表现、对抗样本攻击下还能不能飞，都没有数据。可做的题：设计一个含安全场景的评估基准，测极端条件下的行为。

## 五、跨领域融合机会

### 5.1 VLM 理解 + 世界模型预测

```
VLM（理解当前场景） + 世界模型（预测未来状态） → 更优的规划
```

用 VLM 解析语言指令并识别目标，用世界模型预测执行后的视觉结果，通过预测-执行循环提升规划质量。

### 5.2 世界模型 + 强化学习

```
世界模型（学习环境动力学） + RL（在想象中优化策略） → Dream to Fly 路线
```

在 DreamerV3 框架中加入无人机特有的安全约束和 3D 空间先验。

### 5.3 VLA + 世界模型联合训练

```
VLA（端到端控制） + 世界模型（辅助训练信号） → 数据高效学习
```

用世界模型生成的预测作为 VLA 的辅助损失函数，减少对真实飞行数据的依赖。
