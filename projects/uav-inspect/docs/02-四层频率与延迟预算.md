# 02 四层频率与延迟预算

## 为什么不是"一个循环跑到底"

`code/` 里的 demo 大多是"一步控制、一步物理"，因为要回答的问题不涉及时间。
系统里第一件不能这么做的事就是频率：内环改 1 Hz，机体直接掉；策略层跑 240 Hz，
算力全被前向吃掉。所以四层各有各的周期，而且周期之间必须是整数倍关系。

| 层 | 周期 | 频率 | 谁定这个数 |
|---|---|---|---|
| 物理积分 | 1/240 s | 240 Hz | 接触与积分精度；再低 RK4 也会在贴墙时抖 |
| 控制 | 1/48 s | 48 Hz | 姿态环带宽的 5–10 倍，留出采样余量 |
| 策略（M4） | 1/10 s | 10 Hz | 一次 VLA 前向的预算，见下 |
| 相机 | 1/5 s | 5 Hz | 机载算力下的保守值，也是数据量的上限 |

`configs/default.yaml` 里写的是 `physics_dt: 0.0041667`、`control_dt: 0.0208333`、`policy_dt: 0.1`、`camera_dt: 0.2`，
加载时校验 `control_dt` 必须是 `physics_dt` 的整数倍（5 倍），否则直接 `ConfigError`。
这条校验不是洁癖：不是整数倍时，`advance()` 的余量累积会让"48 Hz 控制"变成 47.3 Hz，
延迟统计全偏，而日志里看不出来。

## 一次动作要经过多少延迟

从"策略想动"到"机体真动"，中间有五段，量级差别很大：

| 段 | 典型量级 | 在本项目里怎么体现 |
|---|---|---|
| 观测采集（相机曝光 + 传输） | 5–33 ms | 相机周期 100 ms，占满一段 |
| 预处理与归一化 | 2–10 ms | `wm/dataset.py` 的归一化，CPU 上毫秒级 |
| 模型前向 | 20–300 ms | M3 的 2.1 M 参数模型在 CPU 上约 10 ms，VLA 会到百毫秒 |
| 通信与排队 | 1–5 ms | 本机进程内，可忽略；真实链路要算 |
| 控制周期等待 | 0–21 ms | 48 Hz 周期的量化误差，最坏要等一整拍 |

把这张表和 chunk 长度对上，就得到 M4 的第一条设计约束：

```
N ≥ ceil(f_control / f_policy) = ceil(48 / 10) = 5 帧
```

一次前向 200 ms 意味着最坏情况要覆盖 0.2 s + 一个控制周期，也就是约 11 拍；
所以动作块长度不能只按"10 Hz 对 48 Hz = 5 帧"取，要按延迟取到 11–12 帧，或者用插值把块之间接起来。这条推导写在
`docs/10-横切判据/03-带宽与频率换算.md`，这里只负责在代码里验证它。

## 实测：延迟不是平均值

M0 的输出里有一张表，来自 `uavinspect/util/latency.py` 的 `StageTimer`：

```
阶段        P50       P90       P99       max
control   0.070 ms  0.096 ms  0.143 ms  0.51 ms
physics   0.738 ms  0.902 ms  1.252 ms  3.9 ms
command   0.006 ms  0.008 ms  0.011 ms  0.03 ms
```

为什么一定要 P99：`physics` 的 P50 是 0.738 ms，P99 是 1.252 ms，差 1.7 倍。
控制周期只有 20.8 ms，单看 P50 会说"余量 28 倍"，看 P99 会说"余量 16 倍"，
而真正决定会不会掉拍的是 max 那一列。`docs/10-横切判据/10-导出与尾部延迟.md`
里给了一个更狠的例子：均值 20 ms、P99 200 ms 的推理服务，每 100 次就有 45 个
250 Hz 周期在执行过期指令。

## 一个容易踩的坑：周期的整数倍

M2 录制时最初按"每步都存一帧"写，结果 1105 个 step 对应 115 张图，`phase` 数组和
`images` 数组长度不一致，按布尔索引取红像素直接报
`IndexError: boolean index did not match indexed array`。修法不是补零，而是让录制器
显式记录 `frame_t`，下游一律按时间戳对齐，不按索引对齐。

这个坑的教训是通用的一层：**只要系统里有两个不同的频率，就一定会有一次"按索引对齐"
的 bug**。所以 `EpisodeRecorder` 存的是绝对时间 `t`，不是帧号。
