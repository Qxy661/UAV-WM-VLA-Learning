# 03 动力学与双后端：一个混控，两种积分

## 为什么会有两个后端

`projects/uav-inspect/` 最初只写了 PyBullet 后端，因为它是这个领域最省事的选择：
刚体、碰撞、接触都是现成的。但本机装不上 pybullet（cp311 没有 wheel，cp39 又卡在
Clash 的假 IP 上），于是 M0 一天也跑不起来。

ADR-008 的结论是：**跑不起来不等于仿真不可信**。把"力怎么变成加速度"这一步抽出来，
用一个只依赖 numpy 的定步长积分器实现，接口与 PyBullet 后端完全一致，
先把 M0 跑到能验收；pybullet 保留在 `--backend pybullet`，等能装上时再对齐数字。

代价写在 ADR 里：两个后端的数字不一样，所以 `metrics.json` 必须记 `sim.backend`，
跨后端比较要先统一后端。

## 共用的那一半：混控与电机

两个后端共用 `uavinspect/sim/dynamics.py` 里的 `QuadModel`，它只做三件事：

1. **反解推力系数**。给定 `mass`、`w_hover`，得 `kf = m·g / (4·w_hover²)`。
   这样"悬停转速 1500 rad/s"就是配置里的物理量，而不是一个拍出来的常数。
2. **混控矩阵**。四旋翼在 (±arm/√2, ±arm/√2) 排布，总推力、俯仰力矩、滚转力矩、
   偏航力矩与四个转速的平方是线性关系：

```
A = [[1, 1, 1, 1],
     [r_y0, r_y1, r_y2, r_y3],
     [-r_x0, -r_x1, -r_x2, -r_x3],
     [k_m/k_f * s0, ..., k_m/k_f * s3]]
```

`mixer_roundtrip()` 是它的自检：给定 (推力, 力矩) 反解转速、再正解回来，
必须逐位相等。这条检查抓过一次符号错：`+y` 方向的参考位置应当产生**负**的滚转力矩，
符号写反时往返仍然成立，只有用物理直觉加一条断言才能发现。

3. **电机一阶滞后**。`rotor.time_constant = 0.03 s`，`motor_step(dt)` 做
   `w += (w_cmd - w) * (1 - exp(-dt/τ))`。加它的理由不是"更真实"，而是不加时
   混控出来的推力是瞬时变化的，任何带宽测试都会得到偏乐观的数字。

## 分歧点：rigid 后端怎么积分

`uavinspect/sim/rigid.py` 的 `RigidQuad` 是 13 维状态（位置 3、速度 3、四元数 4、
角速度 3），RK4 定步长，导数里做四件事：

- 平动：`dv = (R·[0,0,ΣT] + 重力 + 二次阻力) / m`
- 转动：`dω = I⁻¹(τ - ω×Iω)`，惯量按 `[m·a²/2, m·a²/2, m·a²]`
- 四元数：`dq = 0.5 · q ⊗ [0, ω]`，每步归一化
- 接触：位置投影 + 法向冲量（`RESTITUTION = 0.2`、`FRICTION = 0.6`、`STOP_SPEED = 0.05`）

碰撞体是一个球（`collision_radius = 0.08`）对轴对齐盒，球心在盒内时沿最浅轴推出。
机-机之间是等质量球-球冲量。

## 已知不真实的三件事

写在这里，是因为不说清的"物理引擎"最容易被当成真的：

1. **接触只作用在质心**。真实四旋翼撞墙是桨叶先碰，力矩会把机体甩转；
   这里只会得到一个反向冲量。所以撞墙后的姿态不可信。
2. **没有摩擦锥**。`FRICTION = 0.6` 是各向同性的速度衰减，斜着蹭墙不会"卡住"。
3. **机体是刚性球**。四个桨叶、机架、起落架都没有几何，穿越 0.16 m 的门缝
   会比真机容易。

这三条不影响 M0–M6 要验的东西（频率、数据、指标、降级逻辑），但任何"接触动力学"
的结论都不能从这里出。`check_rigid.py` 的七条契约把边界钉在这些不变量上：
自由落体不穿地、双机重叠一步分开、撞墙停在墙前、6 s 悬停 RMSE < 0.30 m。

## 怎么切后端

```bash
py -3.9 projects/uav-inspect/scripts/m0_hover.py --backend rigid
py -3.9 projects/uav-inspect/scripts/m0_hover.py --backend pybullet   # 装得上时
```

`backend: auto` 会探测 pybullet 能否导入，选中的结果写进 `metrics.json` 的 `sim.backend`。
指定 pybullet 但导不进时直接 `RuntimeError` 并提示换 rigid，不静默降级。静默降级会让
"两个后端的数字为什么不一样"变成一个查不出来的问题。
