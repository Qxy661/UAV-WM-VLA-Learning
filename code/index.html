    可运行代码 Demo¶

    二十四个 demo，用来给文档里的结论提供可复现的证据 —— 不是伪代码，是能跑出数、 能画成图、能改参数看变化的脚本。

    除 D 是纯标准库的检索小工具（不依赖 torch）、W 与 X 是纯 numpy 的解析式/蒙特卡洛 实验（不训练任何模型）外，其余二十一个都是真实 PyTorch 实现 （真 nn.Module、真训练循环、真闭环推演），用来验证正文里的技术结论。

    目录结构¶

    code/

    纯 CPU 即可，全部跑完十六分钟左右（本机实测 944.8 秒）；D、I、L、U、W、X 几乎不耗时。每个脚本会打印指标表， 并把图存到仓库根的 figures/。

    D 额外有一个可选开关：--verify 会联网去 arXiv API 核对内置的 51 个 ID （走 https://export.arxiv.org，HTTP 会失败），首次约 10 秒。网络不通时 脚本会打印提示并正常结束，离线出的图和统计不受影响。

    二十四个 demo 分别验证什么¶

    Demo 对应文档 验证的结论 产出图
    A 模型强化学习世界模型 只用先验推演的"想象"能多准地预测回报——这是 Dreamer 用世界模型替代真实环境的依据 wm_loss_curve.png、wm_imagination.png
    B 语言条件飞行控制 模仿损失低 ≠ 闭环飞得好：给专家数据加噪声，模仿损失涨 1000 倍，闭环误差反而降 30% bc_distribution_shift.png、bc_trajectory.png
    C VLA架构演进 多模态动作下，MSE 回归头塌到模态平均，扩散头能采样出两个模态 c_multimodal.png
    D 最新进展与团队追踪 论文产出按团队、按方向怎么看趋势；以及"先核对元数据"能抓出多少引用错误 track_two_labs.png
    E 无人机VLA模型 几何安全校正只看得见最近的那个障碍物：凸形场景把碰撞率从 100% 压到 0，凹形场景反而把它从 51.6% 抬到 77.3% e_gsc_scene.png
    F 机载部署与优化、LLM驱动的无人机Agent 外环延迟收进闭环：连续轨迹指令下 τ=50 ms 误差 16 cm，τ=1 s 就是 1.62 m；换成离散航点后基准抬高、增长却平缓得多 f_latency.png
    G 复现指南-UAV-Flow、复现指南-CognitiveDrone 三个策略跑同一任务算七个指标，换一列指标就换一套名次：动作 MSE 上随机策略排第三（0.426），与高增益的 0.412 几乎并列；换到偏航误差，随机策略升到第二（27.62°），仅次于 PID g_metrics.png
    H 世界模型发展史 不加 symlog 时总体 MSE 看着更小，那是被 x1000 那组独占的假象；symlog 把四组相对误差从 289.9 倍收到 3.6 倍，但代价是总体 MSE 变大 h_symlog.png
    I 生成式世界模型 纯前向平移下中心射线的 Plucker 矩严格不变，边缘射线的位移正比于像半径（位移/半径恒为 0.1111）——透视扩张全由边缘贡献 i_plucker.png
    J 3D场景世界模型 体渲染与 alpha 溅射共用同一个前向合成公式，但公式相同不等于结果相同：残差 0.0787 不随采样密度下降，把深度拉开才收敛到 0.00012 j_render_cost.png
    K 无人机世界模型综述 物理残差只对它写死的那几路管用：位置通道分布外误差降 56 倍，速度通道纹丝不动；rollout 到 1 秒被纯数据模型反超——单步精度不等于长期精度 k_physics_prior.png
    L 关键数据集与基准 全局平移偏差在配准后对两个指标都近乎归零（0.442 m 的偏移残下 ATE 8.25e-16、RPE 3.14e-16）；真正拉开差距的是尺度漂移，2% 的尺度误差配准后仍在，ATE 量到 0.0318 m、RPE 只有 6.57e-04 l_seq_metrics.png
    M 视频生成世界模型 teacher forcing 跑 60 步误差不涨，换成喂自己的输出后第 60 步是第 1 步的 1084 倍；加噪训练买到了抗扰动，却先把单步误差赔掉 8.5 倍 m_exposure_bias.png
    N 边缘VLM部署、机载部署与优化 位宽不是均匀打折：网络落到哪个盆地本身就带来 93% 的基准波动，INT8 在 10 颗种子间从 -9% 摆到 +56%，能确定的只有断崖存在 n_quant_bits.png
    O 环境搭建 等 Part 7 七篇、机载部署与优化、边缘VLM部署 显存四项里三项是精确算术；LoRA 省的是优化器状态（52.2 → 0.9 GB）而不是权重；真实配置的缺口在激活（544 GB 对 25.6 GB 预算，靠梯度检查点补）；只差 batch 的两行能反解出序列长度，但算得通不等于有出处 o_budget.png
    P 动作头与动作分块 块长从 1 拉到 16，策略调用掉到 1/15（120 → 8 次），终点误差只涨 14%（1.3593 → 1.5539 m）：省下来的是调用次数，赔进去的是对策略看不见的阵风的反应 ph6_chunk_horizon.png
    Q 强化学习后训练与自我改进 坏架次占一半时，同一份数据、同一个网络，只换损失里的权重：均匀 BC 3.8593 m，奖励加权 2.5375 m（降 34%）；但坏架次仍拿走 19% 的权重，离全正常架次的 1.3724 m 还差 1.1651 m——软加权压不干净 ph8_reward_weighting.png
    R 评测基准与报告口径 同一批回合三种报法给出三种名次：强风下均值说标准增益好、中位数说高增益好；成功率差 8.6 个百分点的两个策略，64 回合（半宽 11.4 pp）分辨不出、约 120 回合才行；按模型算的区间是按回合算的 2.78 倍 ph9_eval_protocol.png
    S 世界模型增强VLA 单步准不代表多步可用：训练集上一步误差只有 0.0058 m 的世界模型，开环 60 步误差放大 16.1 倍（0.0045 → 0.0719 m），起点稍离训练分布第一步就是 45 倍；想象数据把 8 个种子里训崩的那个救回来（最差 2.7312 → 1.7807 m），离散度收到 34%，但想象步长的最优值量不出来 ph10_wm_data_source.png
    T 世界模型评测与诊断 每一条诊断量都有自己瞎掉的那一族，而且失明是对称的：只看无人机的 D1a 对「目标遗忘」整档恒为 0.0000，只看目标的 D3 对漂移/抖动两族恒为 0.4963（与正常模型逐位相同）；同一个失效在全程平均指标上只体现 0.1356 m，在重现瞬间指标上是 0.9136 m，差 6.7 倍；单步误差相同的两族在 30 步开环下差 √30（实测 5.40–5.52 / 理论 5.477），尾部分位差 1.75 倍 wm7_diagnostics.png
    U 联合嵌入预测与潜空间世界模型 换判据就换编码器：6 维瓶颈下重建派把 4 个高方差方向（全是无关组）装进来，预测派只留 2 个；预测派的重建 RMSE 差 1.10–1.57 倍（它没为此优化过），但线性探针 0.9835 vs 重建派 0.4649（σ²=0.01），且与不压瓶颈的上界 0.9832 几乎重合——瓶颈的损失来自丢掉信号方向，不是多装无用方向 wm8_jepa_probe.png
    V 长时程世界模型与交互式生成 没有一种外推方式在全 horizon 上占优：短遮挡下冻结是 O(K)、匀速外推是 O(K²)，中段差距最大；K=160 步时冻结的跳变（3.139 m）反超为优，但它持续喂错带来的累积偏离反而更大（遮挡期 1.491 vs 1.040 m）——失效是「持续错误 + 一次跳变」两段；最优记忆时间常数随遮挡长度单调下移，K=160 时收敛到 3.2 秒，与目标机动特征时间 1/ω = 1.67 秒同阶 wm9_longhorizon_memory.png
    W 通用VLM架构与视觉编码器 压视觉 token 先崩的是定位、不是描述：B 从 576 压到 4，计数与主导象限恒为 1.0000（整数求和与格子划分无关），而左右判断从 0.9799 掉到 0.7512、单体定位误差涨 12.0 倍；判断左右只用 1 个坐标，同列率是 1/G 而不是 1/B；命中率与 B 成正比（B 从 64 到 576 是 9 倍，命中率 0.0808 → 0.7295）；把 token 集中给目标象限，该区好 1.48 倍、其余三区各差 1.34 倍，按面积加权整体反而差 1.17 倍 w_token_budget.png
    X 通用VLM评测与幻觉 换一套负样本就换一个名次：图像盲的先验模型在 random 档拿到 0.9250 并排第一，换成 popular 负样本掉到 0.4970（差 0.4280），而它的 Recall 三档恒为 0.9400；翻转是有条件的——正题类频集中度 β=1.00 时它排第二，β ≥ 1.25 才翻过来，但 popular 档下它一律垫底（0.4970–0.5190）；它的 yes-ratio 从 0.5150 升到 0.9430，说明 0.4970 这个准确率不是「随机猜」而是「在猜 yes」 x_hallucination_metric.png

    仿真的约定¶

    A/B/E/F/G/K/P/Q/R/S/T/V 十二个 demo 共用一个极简四旋翼模型（common/quad_sim.py）。其余 demo 用不到它。

    状态 12 维:  [p(3), v(3), rpy(3), omega(3)]     位置、速度、姿态角、角速率
动作  4 维:  [thrust, wx, wy, wz]              归一化总距 + 三轴角速率
dt = 0.02 s（50 Hz）

    坐标轴是对角约定：正 roll → +x 加速，正 pitch → +y 加速。真实四旋翼不是这么定义的， 这里换成对角形式，是为了让"哪个轴修正哪个误差"一眼能看出来 —— Demo B 里那个 "侧向轴交叉耦合"的 bug 正是靠这个约定才暴露出来的。

    它不是气动仿真器，只是"够用的被控对象"。要接真机请走 PX4 那条路，见下。

    实测环境¶

    Python 3.9.12 | torch 2.6.0+cu124 | numpy 2.0.2 | scipy 1.13.1 | matplotlib 3.9.4

    Windows / Linux 均可；matplotlib 用 Agg 后端，无显示器也能存图。 中文字体按 Microsoft YaHei → SimHei → Noto Sans CJK SC → … 的顺序自动挑， 一个都没有时会退回英文而不是画一屏方块。

    上面那张运行时间表是在 CPU（单机四线程）上量的；换机器会有出入，量级不变。
